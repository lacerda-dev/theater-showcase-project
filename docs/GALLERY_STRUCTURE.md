# Galeria

## Objetivo

Permitir que visitantes acompanhem a história da companhia através dos registros de apresentações, ensaios e eventos.


## Pergunta que responde

- Como são os eventos da companhia?
- Meu filho vai gostar desse ambiente?
- A companhia realmente realiza apresentações?
- O ambiente parece acolhedor?
- A companhia é ativa?


## O visitante deve sentir

- confiança
- proximidade
- pertencimento
- vontade de participar
- admiração


## Elementos

- banner da página
- lista de eventos
- imagem de capa de cada evento
- título
- data


## Não deve conter

- textos longos
- excesso de informações
- poluição visual
- muitas animações


## Critério de sucesso

O visitante deve conseguir imaginar seu filho participando daqueles momentos.

# Página de Evento

## Objetivo

Mostrar todas as fotos daquele evento.


## Pergunta que responde

"Como foi esse evento?"


## Deve conter

- capa
- título
- descrição
- data
- grid de imagens
- lightbox


## Critério de sucesso

O visitante deve permanecer navegando pelas fotos.
